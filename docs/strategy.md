# 종목·전략

`strategy.html`은 보유수량·평균매입가·매수 구간·덜어내기·1/2차 매도·1차/핵심 지지·메모를 브라우저에 저장합니다. 공개 저장소에 개인 보유내역을 올리지 않습니다. 국내 종가를 기존 일일 API 파일에서 읽어 구간 진입을 점검합니다. 통화가 다른 종목은 합산하지 않습니다. AI 검토문 복사는 입력 정보와 수집 기준일을 정리하는 기능이며 LLM API 호출이 아닙니다.

시장 US는 Twelve Data 수집 자료가 연결된 경우에만 가격을 표시합니다. 현재 PER 프로젝트에서는 키 위치/등록이 확인되지 않아 미국 시세를 성공 상태로 표시하지 않습니다. `scripts/collect-twelve.py`는 실제 키를 숨긴 표준입력으로 받아 quote 엔드포인트를 조회하는 준비된 수집기입니다. 결과는 무시된 `.sites-runtime/`에만 저장하며 자동 공개하지 않습니다. 키는 소스나 GitHub Pages에 넣지 않습니다. 공개 표시 권한이 확인된 수집값은 일일 파일의 `twelveQuotes` 배열에 연결할 수 있습니다. 실시간/지연 여부는 실제 구독·응답 기준을 따르며 임의로 실시간을 주장하지 않습니다.

키 등록 위치가 확인된 후 실제 인증 응답을 검증해야 연결 완료입니다. 공식 문서: https://twelvedata.com/docs
